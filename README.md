# Semgrep JSON to HTML Converter

A lightweight utility for transforming Semgrep JSON output into clean, human-readable HTML reports.

## Overview

This project simplifies the process of analyzing static code findings by converting raw Semgrep scan results (JSON format) into structured and visually accessible HTML reports. It is designed for developers, security engineers, and DevSecOps teams who want better readability and shareability of scan results.

## Features

* Converts Semgrep JSON output into well-formatted HTML
* Highlights vulnerabilities with clear categorization and severity levels
* Easy-to-navigate report structure for quick analysis
* Lightweight and fast processing
* Suitable for CI/CD pipeline integration

## Use Cases

* Security audit reporting
* Code review enhancement
* CI/CD pipeline result visualization
* Sharing scan results with non-technical stakeholders

## Getting Started

1. Run Semgrep and export results in JSON format
2. Use this tool to convert the JSON file into an HTML report
3. Open the generated HTML file in any browser

## Why This Tool?

Raw JSON output from Semgrep can be difficult to interpret quickly. This tool bridges that gap by providing a clear, structured, and visually intuitive representation of findings.
